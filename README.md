# Nexus Portfolio

Portfólio institucional estático desenvolvido com HTML, CSS e JavaScript puro.

## Como executar
Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Personalização antes de publicar
1. Substitua os projetos demonstrativos por trabalhos reais e autorizados.
2. Atualize o número de WhatsApp em `js/main.js`.
3. Atualize o domínio em `sitemap.xml` e `robots.txt`.
4. Confirme informações, serviços, textos e links da empresa.
5. Teste em celular e desktop e publique com HTTPS.

As fontes DM Sans e Manrope são carregadas do Google Fonts; sem internet, o site usa fontes genéricas de fallback.


## Identidade visual
A logo fornecida foi recortada para remover as margens pretas vazias e está em `assets/images/nexus-symbol.png`. O site usa preto, branco e magenta para combinar com a marca. O favicon foi deixado sem vínculo no HTML para que você adicione o seu arquivo depois. Quando tiver o favicon, coloque-o em `assets/icons/` e adicione a tag `<link rel="icon" href="assets/icons/SEU-ARQUIVO.ico">` dentro do `<head>` do `index.html`.

Antes de publicar, substitua o número de WhatsApp de exemplo em `js/main.js`, configure o domínio em `sitemap.xml` e troque os projetos conceituais pelos trabalhos reais.
